- **AI Founding Engineer Intern @ [EpicWise](https://epicwise.io)** (Canada startup) — building the core context engine: multi-step LangGraph pipelines, a public MCP server, and hybrid retrieval combining Pinecone vector search with Neo4j graph traversal.

- **Frontend Developer Intern @ [FaxLab](https://www.faxlab.in/)** — shipped course catalog, auth flows, and learner dashboards for an AI course platform, on time with zero QA rollbacks.

- **[Evident](http://evident.kaushalendra.me/)** — turns any URL into structured, typed data with transparent confidence scores instead of raw scraped text. Open-source, MCP-first, built so AI agents know when to trust what they extract.

- **[RepoGraph AI](http://repograph.kaushalendra.me/)** — VS Code extension that maps every file relationship in a workspace into an interactive dependency graph, so engineers can understand an unfamiliar codebase quickly. Integrates multiple AI providers with a multi-turn Q&A agent grounded in the graph and file context.

- **[Buildify Labs](https://www.buildifylabs.in)** — agentic BI platform where a LangGraph (ReAct) agent converts natural language into SQL and live dashboards, with memory for multi-step, follow-up queries.

- **[GRS Worker Portal](https://grsworker.com)** — production worker-management system covering attendance, payroll, and admin operations, with structured validation and a Dockerized CI/CD pipeline for safe releases.

- **[Attendance Tracker](https://myattendance-eta.vercel.app)** — real-time PWA attendance system with role-based access control and a caching layer for high concurrency.

- **[Postly](https://postly-lake.vercel.app)** — real-time social platform on Socket.IO with Kafka-based async event processing for live updates.

- **[AI Context Engine](https://github.com/Kaushalendra-Marcus/ai-context-engine)** — context-aware backend using RAG and vector search to turn raw documents into structured, queryable insights.

- **[TwitterBotAI](https://tweetbotai.vercel.app)** — AI-powered tweet automation on Gemini, pulling from news, RSS, and custom-prompt sources.

- Contributor to **[Joplin](https://github.com/laurent22/joplin)** — opened pull requests against the desktop app, mobile, and sync engine, with fixes merged and reviewed by upstream maintainers.

Currently exploring agent reliability & evals, fine-tuning small models for narrow tasks, and graph-based retrieval at scale.
